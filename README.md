About

ExamSirAngelo is a web-based exam preparation platform designed around a simple idea:

Study like you're in your own training arc.

Practice questions, test your knowledge, learn from mistakes, and keep improving until you're ready for the final exam.

Getting Started
Clone

cd ExamSirAngelo

Install
npm install

Development
npm run dev

Production
npm run build
