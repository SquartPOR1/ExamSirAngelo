## ✨ ABOUT THE PROJECT

**ExamSirAngelo** is a project focused on making exam preparation more engaging, organized, and accessible.

Whether you're reviewing lessons, practicing questions, or preparing for your next challenge, the goal is simple: **learn consistently, improve continuously, and achieve more.**

## 🌌 FEATURES & VISION

- 📚 **Exam Preparation** — Build a stronger foundation through focused study.

## 🚀 GETTING STARTED

Clone the repository and install its dependencies:

```bash
git clone https://github.com/SquartPOR1/ExamSirAngelo.git
cd ExamSirAngelo
npm install
npm run dev
```

Make sure Node.js is installed. These commands assume the repository contains a compatible `package.json` with a `dev` script.
