ExamSirAngelo

Your exam. Your training arc. Your result.

ExamSirAngelo is an exam-focused web application built to make studying more interactive and engaging. It provides a platform for practicing questions, testing knowledge, and preparing for exams through a focused, anime-inspired experience.

Overview

Studying is a process.

You start with what you know, identify what you don't, practice until you improve, and eventually face the final challenge.

ExamSirAngelo is built around that idea.

Installation

Clone the repository:

git clone https://github.com/SquartPOR1/ExamSirAngelo.git


Move into the project directory:

cd ExamSirAngelo


Install the dependencies:

npm install


Start the development server:

npm run dev


Vite will provide the local development URL in your terminal.

Production Build

Create a production build with:

npm run build


Preview the production build locally:

npm run preview
